JithuBrowser

A privacy-focused browser built on official Chromium

Websites keep working, including Chrome-only ones, and Chrome Web Store extensions install normally. Pages just can't watch what you do. Canvas, WebGL and audio fingerprints are blurred, keystroke timing is jittered so typing rhythm can't identify you, the keyboard layout and client hints look like a stock install, and a page can't tell when you switch tabs or windows.

It is 23 patches2 on top of Chromium 155, each protection a feature flag that can be turned off per site. On Linux it passes all 35 tests of its privacy suite, where stock Chrome fails 313.

What isn't done

The Windows installer is cross-compiled on Linux and passes the suite under Wine, but it has not been run on real Windows yet. The README says so at the top.

C++, Chromium, Python, pytest. Pre-release for Linux and Windows.

Craftie

An AI coworker for Minecraft that joins your world as a second player

Ask it in chat for a house, twenty iron or a set of armor and it works out every step itself: which tool it needs first, where to mine, what to smelt. The rest of the time it follows you, defends you, rescues your items when you die, and keeps itself fed and equipped. Up to four of them can split a big build between them.

The AI only decides what to do. Pathfinding, mining, crafting, building and fighting are plain code running at game speed, so most jobs need one AI call4, and following or fighting need none. It works with Claude, OpenAI, OpenRouter, DeepSeek, or a free local model.

What isn't done

Survival builds from an empty inventory take twenty minutes or more, because it gathers everything itself. Bedrock Edition is not supported.

TypeScript, Mineflayer, SQLite, Fabric. A fan project, not affiliated with Mojang or Microsoft.

NexCC

An optimizing compiler for a C subset where nothing is hidden. Built with a teammate.

Teaching tools usually show one fragment, such as a regex becoming an automaton, and real compilers bury the classical stages in millions of lines. NexCC keeps the whole path visible in one workbench: tokens, syntax tree, three-address code, control-flow graph, SSA form, each optimization pass as a diff, and the RISC-V assembly that comes out.

The optimizer runs mem2reg, sparse conditional constant propagation, global value numbering, loop-invariant code motion and dead code elimination. The backend allocates registers by graph coloring and emits RV32IM. A second backend is a bytecode VM that catches out-of-bounds and use-after-free accesses and can step backwards5 through execution.

JavaScript, Node.js. Includes automata and LL/LR grammar labs.

Diabetic retinopathy screening

Smart India Hackathon 2026, problem statement 26038

Give it a photo of the back of the eye and it answers clear, refer or escalate to a person. A ResNet-50 grades the image. A Grad-CAM heatmap of where the model looked is then checked against lesion evidence from two independent detectors, and a rule-based policy escalates whenever the image is poor or the evidence disagrees, instead of trusting the classifier alone.

At the frozen operating point it reaches sensitivity 0.982 and specificity 0.9176 on validation. Accuracy alone is never reported.

What didn't make it

One configuration let the pipeline decide more cases without a person, but it sent two referable patients home7 where the classifier alone sent none. It was rejected, and the reason is written down as a decision record.

MATLAB, Simulink, ResNet-50, U-Net. A research prototype, not a medical device.

Agent spend policy engine

Decides whether an AI agent may pay for something, before any money moves

Approved payments settle for real on Algorand testnet through the x402 protocol: request, get a 402, pay, retry, get a 200. The APIs behind the paywall are real too, with live weather from Open-Meteo and company lookups from SEC EDGAR.

Every decision, allowed or blocked, goes into a log where each entry carries the hash of the one before it, and the latest hash is written to Algorand. Anyone can confirm the record wasn't rewritten in about ten seconds8, without trusting whoever runs the system. The dashboard has a button that tampers with a past record, and verification names the exact entry that changed.

A new reader can go from git clone to a paid API call in about fifteen minutes9.

FastAPI, Pydantic, Algorand, x402, testnet USDC.

Ayur-Ai

Names an Ayurvedic medicinal leaf from a photo, then looks up what it's used for

A ResNet18 fine-tuned in PyTorch identifies 30 species, and a TF-IDF search over a herb knowledge base finds their uses or matches herbs to a symptom. It runs fully offline, with no LLM and no API keys, and trains in about two minutes on a laptop GPU.

Many photos in the dataset show the same physical leaf, so near-duplicates are grouped and kept on one side of every split. Under that rule it scores 98.64% accuracy10 in 5-fold cross-validation. A single split swings between 0.87 and 1.0011 depending on the random seed, which is why the cross-validated number is the one quoted.

PyTorch, scikit-learn, Streamlit. Educational, not medical advice.
