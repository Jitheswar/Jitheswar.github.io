01 Privacy browser

JithuBrowser

A privacy-focused browser built on official Chromium.

3 starsUpdated Oct 2026

31/35

privacy tests that stock Chrome fails3 on Linux. JithuBrowser passes all 35.

23 patches2 on Chromium 155, each one a switch you can turn off per site

Websites keep working, including Chrome-only ones, and Chrome Web Store extensions install normally. Pages just can't watch what you do.

More detail

Canvas, WebGL and audio fingerprints are blurred, keystroke timing is jittered so typing rhythm can't identify you, the keyboard layout and client hints look like a stock install, and a page can't tell when you switch tabs or windows.

What isn't done. The Windows installer is cross-compiled on Linux and passes the suite under Wine, but it has not been run on real Windows yet. The README says so at the top.

C++, Chromium, Python, pytest. Pre-release for Linux and Windows.

02 AI teammate

Craftie

An AI coworker for Minecraft that joins your world as a second player.

Updated Nov 2026

1

AI call is all most jobs need4. Following you and fighting need none.

Up to 4 Crafties can split one big build between them

Ask it in chat for a house, twenty iron or a set of armor and it works out every step itself: which tool it needs first, where to mine, what to smelt.

More detail

The rest of the time it follows you, defends you, rescues your items when you die, and keeps itself fed and equipped. The AI only decides what to do. Pathfinding, mining, crafting, building and fighting are plain code running at game speed. It works with Claude, OpenAI, OpenRouter, DeepSeek, or a free local model.

What isn't done. Survival builds from an empty inventory take twenty minutes or more, because it gathers everything itself. Bedrock Edition is not supported.

TypeScript, Mineflayer, SQLite, Fabric. A fan project, not affiliated with Mojang or Microsoft.

03 Compiler

NexCC

An optimizing compiler for a C subset where nothing is hidden. Built with a teammate.

Updated Oct 2026

17

tests cover every stage, from regex automata to a VM that can step backwards5.

5 optimizer passes on SSA, then a RISC-V backend

Teaching tools usually show one fragment, and real compilers bury the classical stages in millions of lines. NexCC keeps the whole path visible in one workbench: tokens, syntax tree, three-address code, control-flow graph, SSA form, each optimization pass as a diff, and the RISC-V assembly that comes out.

More detail

The optimizer runs mem2reg, sparse conditional constant propagation, global value numbering, loop-invariant code motion and dead code elimination. The backend allocates registers by graph coloring and emits RV32IM. A second backend is a bytecode VM that catches out-of-bounds and use-after-free accesses and can step backwards through execution.

JavaScript, Node.js. Includes automata and LL/LR grammar labs.

04 Medical imaging

Diabetic retinopathy screening

Smart India Hackathon 2026, problem statement 26038.

2 starsUpdated Sep 2026

0.982

sensitivity, at specificity 0.9176 on validation. Accuracy alone is never reported.

3 answers: clear, refer, or escalate to a person

Give it a photo of the back of the eye and it answers clear, refer or escalate to a person. A ResNet-50 grades the image, and a heatmap of where the model looked is checked against lesion evidence from two independent detectors.

More detail

A rule-based policy escalates whenever the image is poor or the evidence disagrees, instead of trusting the classifier alone.

What didn't make it. One configuration let the pipeline decide more cases without a person, but it sent two referable patients home7 where the classifier alone sent none. It was rejected, and the reason is written down as a decision record.

MATLAB, Simulink, ResNet-50, U-Net. A research prototype, not a medical device.

05 Verifiable payments

Agent spend policy engine

Decides whether an AI agent may pay for something, before any money moves.

Updated Sep 2026

10 s

is about how long8 it takes anyone to confirm the log wasn't rewritten, without trusting whoever runs it.

About 15 minutes9 from git clone to a paid API call

Every decision, allowed or blocked, goes into a log where each entry carries the hash of the one before it, and the latest hash is written to Algorand.

More detail

Approved payments settle for real on Algorand testnet through the x402 protocol: request, get a 402, pay, retry, get a 200. The APIs behind the paywall are real too, with live weather from Open-Meteo and company lookups from SEC EDGAR. The dashboard has a button that tampers with a past record, and verification names the exact entry that changed.

FastAPI, Pydantic, Algorand, x402, testnet USDC.

    06 Offline classifier

    Ayur-Ai

    Names an Ayurvedic medicinal leaf from a photo, then looks up what it's used for.

    Updated Sep 2026

    98.64%

    accuracy in 5-fold cross-validation10, with near-duplicate photos kept on one side of every split.

    30 species, no LLM, no API keys, no network

    A ResNet18 fine-tuned in PyTorch identifies 30 species, and a TF-IDF search over a herb knowledge base finds their uses or matches herbs to a symptom. It runs fully offline and trains in about two minutes on a laptop GPU.

    More detail

    Many photos in the dataset show the same physical leaf, so near-duplicates are grouped before splitting. A single split swings between 0.87 and 1.0011 depending on the random seed, which is why the cross-validated number is the one quoted.

    PyTorch, scikit-learn, Streamlit. Educational, not medical advice.
