07NLP · PyTorch · Team project

onepass-zsc

Zero-shot classification for any number of labels in one forward pass.

The usual approach runs the model once per label, so 77 labels cost 77 passes. onepass packs every label into one sequence behind a block attention mask: labels can't see each other and the text is encoded once. Probabilities are calibrated on datasets the benchmark never touches.
