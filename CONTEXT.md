# Portfolio

The personal site for Jitheswar: a public, permanent home for a selected body of engineering work.
It exists to convince one specific kind of reader that the thinking behind the work is sound.

## Language

### Readers

**Primary Reader**:
The engineer or hiring manager running a technical screen, who will read a project in depth to judge whether the interesting decisions in it were the author's own.
Every trade-off resolves in this reader's favour.
_Avoid_: user, visitor, audience.

**Secondary Reader**:
The recruiter who screens first and skims for role fit before passing the link on.
Served only to the extent that they do not bounce.
_Avoid_: HR, hiring.

### Design language

**Restrained Clay**:
The site's material treatment: soft extruded surfaces, generous radii, and tactile depth, carried by a saturated and disciplined palette rather than a pastel one.
It is a material, not a tone; the work it presents is serious and the surface must not undercut it.
_Avoid_: claymorphism (the unqualified term implies the pastel, toy register that was rejected), neumorphism, soft UI.

**Fun**:
A quality of interaction, not of decoration: every interactive element responds physically to input, and each screen holds at least one moment of genuine delight.
Decorative motion that exists only to be noticed is not Fun and does not qualify.
_Avoid_: playful, whimsical, animated.

**Practical Floor**:
The set of hard performance and accessibility budgets that a build must pass, against which any visual effect is checked.
An effect that cannot fit inside the Floor loses; the Floor is never relaxed to admit an effect.
_Avoid_: performance budget, best practices, polish.

### Content

**Case Study**:
A project entry of roughly 600 to 900 words following one fixed spine: the problem, the constraint that made it hard, the decision taken and the alternative rejected, the honest numbers and known limits, then the code link.
The spine is identical across every Case Study so that a reader who liked one knows where to look in the next.
_Avoid_: project page, write-up, portfolio piece, blog post.

**Card**:
A shallow project entry: a title, a one-line claim, and a link out, with no spine and no long-form body.
A project is either a Case Study or a Card; there is no middle depth.
_Avoid_: tile, teaser, summary.

**Set-Piece**:
The single deliberate moment of delight on a screen, distinct from the baseline physical response that every interactive element already owes under Fun.
There is at most one per screen.
_Avoid_: hero animation, easter egg, wow moment.

### Surface

**Source**:
The image a page's palette hue is derived from, and the subject of the site's one Set-Piece.
It contributes hue only; saturation and lightness are fixed in code so that Restrained Clay survives any Source.
_Avoid_: wallpaper, background image, theme.

**Carve**:
The name treatment: text pressed into the clay sheet rather than raised from it, rendered in a real ink colour so it passes contrast rather than as transparent text carried by shadow.
_Avoid_: deboss, emboss, inset text, engraved.
